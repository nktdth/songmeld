# SongMeld

<img src="branding/songmeld-logo-orange.svg" alt="SongMeld orange logo" width="96" />

SongMeld is a modern open-source Android music toolbox built with
Kotlin, Jetpack Compose, and Material 3.

**MELD** stands for **Metadata, Editing, Lyrics, Download** — the four core areas
SongMeld aims to bring together.

> SongMeld is currently under active development.

## Status

SongMeld is being rebuilt from the ground up.
Features and APIs may change frequently during early development.

## Branding

The README uses the [orange and dark brown logo](branding/songmeld-logo-orange.svg), matching SongMeld's Android 8–11 fallback palette (`#FFA069` and `#57331E`). The [full branding SVG](branding/songmeld-logo.svg) and [standalone music/wrench mark](branding/songmeld-mark.svg) share the same optically centered note geometry. Android 12+ uses wallpaper-based dynamic colors at runtime. See the [branding guidelines](docs/branding.md).

## Typography

SongMeld uses Google Sans Flex for Material 3 UI text and Google Sans Code for
timecodes and future editors. The project keeps the fonts in
`app/src/main/res/font/` and their OFL 1.1 license in
`app/src/main/assets/licenses/`. See [font details](docs/fonts.md).

## Icon catalog experiment

Settings → Appearance → Icon appearance → Browse icons contains an **offline icon picker** for full Material Symbols, MDI, and Flutter Material Icons fonts. The current project snapshot includes the fonts and search indexes, so **building does not require an external APK**. To refresh them from the upstream publishers, use `tools/sync_official_icon_fonts.py` (see [the icon system guide](docs/icon-system.md) for the separate, version-pinned download, license, and verification steps).

```bash
chmod +x gradlew
./gradlew installDebug
```

The font-sync script is optional for normal builds. Its `--verify` command requires a lockfile generated by a successful sync; an imported snapshot without that lockfile is not proof that the existing binaries were downloaded from upstream by the script. For user-interface references, see [Material 3 examples](docs/material3-references.md).
